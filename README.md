# Memory Lane

A web application that allows visitors to upload
photographs and automatically displays them on a
dedicated TV or computer screen.

## Technology Stack
- React.js
- FastAPI
- SQLite
- SQLAlchemy
- WebSockets

## Project Status
Phase 1 - Initial Setup

## Running the Project
Setup instructions will be added as development progresses.


# Project Assumptions

1. Each visitor receives a unique access code.
2. Visitors must provide consent before photo display.
3. Supported formats: JPG, JPEG, PNG and WEBP.
4. Maximum image size: 10 MB.
5. Maximum 10 images per upload session.
6. Each photo is displayed for 7 seconds initially.
7. Only consented and successfully uploaded photos
   are eligible for display.
8. Returning visitors can retrieve previous photos.
9. An admin can remove inappropriate photos.
10. The initial application runs locally.
